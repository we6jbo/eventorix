# Optional public integration

Use an explicitly configured public executable or trusted package wrapper. Pass arguments separately using QProcess or equivalent; verify JSON and exit status. Do not invoke a shell with event text. Do not fall back to another edition. Use asynchronous or worker-thread calls; remain functional if Eventorix is absent.

For opt-in meaningful usage tracking, create a stable UUID per project version and review purpose. At the configured threshold, schedule a 14-day distribution review with `schedule --after 14d --source APP --assigned-to all --id UUID --message MESSAGE`. Verify the returned event ID, source and message. Retry with the same identifier. Use hidden persistent state; do not auto-publish. Pending/overdue events persist; complete or delete only on explicit authorization.
